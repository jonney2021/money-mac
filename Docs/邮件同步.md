# 免费邮件自动记账：Windows 助手 + 加密文件

这套方案不需要租服务器。Windows 电脑运行时，每 5 分钟检查收件箱中的指定发件人通知。识别成功后更新加密文件；同步盘送到 iPhone，用户选定文件后，小家在**解锁和手动刷新**时导入。电脑关闭、授权失效、云盘不更新或 App 未打开时不会实时入账。

## A. 先确认银行通知格式

通用解析器目前只接受类似：

> Your card ending 1234 was used at COSTCO for CAD 86.42 on 2026-10-24.

必须包含购买/消费语义、明确 CAD（或 C$）、一个金额、商户和 YYYY-MM-DD 交易日期。只有 `$`、多个金额、日期不明确、退款/还款/账单/待处理通知会跳过。真实银行通知经常格式不同，因此**需要先用一封脱敏样本适配解析器，不能保证开箱即用**。

发件人白名单不证明邮件真实性，也无法识别所有授权/结算重复通知。自动导入都标为待核对且计入统计，请核对最终实际交易。若同一交易被银行用不同邮件 ID 再发一次，可能出现两笔，需手动删除其中一笔。

## B. 准备共享文件位置

可以使用你已有的免费 iCloud Drive 空间，或支持 iPhone「文件」App 的其他同步盘。先确认能在 Windows 生成文件并在 iPhone 看到同一文件；有些服务的安全书签/文件按需下载行为不同，必须实测。

Apple iCloud Drive 官方说明：https://support.apple.com/en-ca/118443

只同步 `.hearthfeed` 文件，不同步 Windows 凭据目录。加密文件由配对密钥保护。不要把密钥、真实邮件或配置上传 GitHub。

## C. Windows 安装

1. 安装 Python 3.11+（https://www.python.org/downloads/windows/）。
2. 下载源码并解压，进入 `Companion`。
3. iPhone 小家 → 邮件 → 生成配对密钥。只在你自己的电脑上输入，勿分享。
4. 双击 `setup.cmd`。它创建本地 Python 环境并从 PyPI 安装 requirements 中的依赖。
5. 记事本打开 `config.json` 后，修改非秘密配置：邮箱、明确银行发件人、同步文件完整路径。保存并关闭记事本，回到终端继续。
6. 按提示配对并授权邮箱。之后双击 `run.cmd`，保持窗口运行。Ctrl+C 停止。

配置文件由 `config.example.json` 复制，**不要直接提交实际 config.json**。第一次运行后，在 iPhone 邮件页选择生成的 `.hearthfeed` 文件。

Windows 本地凭据保存在当前用户 Credential Manager / DPAPI，历史记录在 `%LOCALAPPDATA%\HearthNative` 的加密文件里；不会写入 config.json，不记录邮件正文。生产邮箱调用未在开发环境验证。

## D. Outlook / Hotmail

采用你自己注册的 Microsoft 公共客户端应用与设备代码授权。**不要使用 Outlook 密码或应用专用密码替代 OAuth，也不需要 client secret。**

1. 在 Microsoft Entra 管理中心创建应用注册（https://entra.microsoft.com/ → App registrations → New registration）。选择支持个人 Microsoft 账户的账户类型。
2. Authentication 中启用 **Allow public client flows**。
3. API permissions → Microsoft Graph → Delegated permissions → 添加 **Mail.Read**。不要添加 Mail.ReadWrite 或 Mail.Send。本程序只读取邮件。
4. 将 Application (client) ID 写入 config.json 的 `client_id`；`provider` 为 `outlook`，`email` 是你实际用于接收通知的邮箱。
5. 运行 setup，在自己浏览器中打开 Microsoft 提供的 device login 地址，用提示的一次性设备代码完成授权。代码只显示在你的本地终端，不要粘贴到聊天或 GitHub。

应用注册可用性取决于你的 Microsoft 租户/账号权限；如果没有 App registrations 权限，需要先解决该账号权限，不能保证任何个人账号都能直接新建租户。App 注册、授权和实际邮件读取尚需你本人完成验证。

官方参考：
- https://learn.microsoft.com/en-us/entra/msal/python/getting-started/acquiring-tokens
- https://learn.microsoft.com/graph/tutorials/python/

## E. Gmail

1. Google 账号开启两步验证，并确认可创建应用专用密码。
2. provider 改为 `gmail`，填写 Gmail 地址、银行发件人和输出文件路径；client_id 可留空。
3. setup 提示时输入 Gmail 应用专用密码，**不是 Google 登录密码**。
4. Gmail IMAP 读取 INBOX，使用只读模式及 BODY.PEEK，不修改已读状态。

某些组织账号/高级保护设置不允许应用专用密码；不可用时应采用正式 OAuth 适配，当前助手没有实现 Gmail OAuth。

官方说明：https://support.google.com/accounts/answer/185833

## F. iPhone 配对与自动导入

1. App「邮件」页生成密钥，Windows setup 输入同一密钥。
2. 运行助手产生 `mail.hearthfeed`，等待云盘同步，在 iPhone 文件 App 确认已下载。
3. App「邮件 → 选择加密同步文件」选中它。App 保存安全书签；下一次解锁读取更新。
4. 查看「明细 → 待核对」。确认金额、日期、商户、分类后保存。
5. 一封邮件的相同邮件 ID 仅导入一次；删除该记录后会保留忽略标识。

同步文件累计上限 10,000 笔，超出会停止写入而非自动丢弃历史。需先备份账本、停止助手，再归档旧同步文件及本地加密历史，重新开始；不要在不了解去重和备份的情况下删除本地文件。

恢复整本账本后，为避免书签指向旧设备，需要重新选择同步文件。配对密钥包含在加密账本备份中；Face ID 不随备份迁移。

## 隐私与权限

Outlook 的 Mail.Read / Gmail IMAP 授权可以访问较多邮件，即使程序只筛选银行通知。请在自己的电脑授权并保管凭据。停止使用时，在 Microsoft/Google 账号安全页面撤销相应应用/应用专用密码；在 Windows 凭据管理器删除对应 HearthNative 条目，并移除本地 DPAPI 缓存。不要关闭杀毒或 TLS 校验来排错。
