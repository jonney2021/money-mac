# Windows → iPhone 免费安装与日常使用

## 1. 确认条件

- iPhone 系统 iOS 17 或更新版本，Windows 电脑，USB 数据线。
- 免费 Apple 账号；不需要付费开发者会员。
- GitHub 仓库为公开、Actions 成功，已拿到该次构建的 unsigned IPA。
- 首次安装要在你自己的电脑/iPhone 完成 Apple 登录、信任与开发者模式操作；本项目不会索取 Apple 密码。

## 2. 云端构建

打开本仓库 Actions → Build iPhone App。如果自动构建没有运行，点 Run workflow。等待所有步骤变为绿色。

在该次运行详情底部 Artifacts 下载 `Hearth-iPhone-unsigned` ZIP（GitHub 可能要求登录）。解压得到 `Hearth-unsigned.ipa` 和 `SHA256SUMS.txt`。不要把 ZIP 当成 IPA 安装；也不要下载失败运行留下的旧产物。

## 3. 安装 AltStore Classic

使用官方说明：https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows

1. 下载 AltServer for Windows，按官方当前要求安装 Apple 设备支持、iTunes/iCloud。Microsoft Store 版本兼容问题以官方 Troubleshooting Guide 为准，不要从陌生镜像下载旧组件。
2. USB 连接 iPhone，解锁并信任这台电脑。
3. Windows 任务栏 AltServer 图标 → Install AltStore → 选择你的 iPhone。
4. 在自己的电脑本地完成 Apple 账号验证。不要把密码输入到本仓库或发给聊天助手。
5. iPhone 设置 → 通用 → VPN 与设备管理，按提示信任自己的开发者身份。若系统要求，设置 → 隐私与安全性 → 开发者模式，重启并确认。
6. 打开 AltStore Classic，按提示完成账户验证。

注意是 **AltStore Classic + 自己的 AltServer**。本说明不使用 PAL、第三方共享签名或远程签名服务。

## 4. 安装小家

将 `Hearth-unsigned.ipa` 放到你能从 iPhone「文件」App 打开的位置。打开 AltStore → My Apps → `+` → 选择 IPA。让自己的 AltServer 在 Windows 上运行，并保持 USB 或同一网络连接。

安装成功后，iPhone 主屏幕会出现「小家」。首次建立本机用户名和密码（至少 10 个字符）。在「设置 → 启用 Face ID / Touch ID」完成系统验证。

## 5. 每周刷新与更新

免费签名每 7 天到期。每周到期前打开 AltStore → My Apps → Refresh All。开启自动刷新并保持 AltServer 可连接有帮助，但请检查实际剩余天数。

- 到期不能打开 App ≠ 账目已丢失。
- **不要卸载小家再刷新。**用同一 Apple 账号、同一 App 标识覆盖签名安装。
- 更新版本也先导出 `.hearth` 加密备份，再覆盖安装新 IPA。
- App ID 默认为 `app.hearth.familyledger`；更改 ID 可能导致 iOS 把它看成另一个 App。
- AltStore 本身占一个免费侧载 App 名额。

## 6. 日常使用

- 总览：当月收入、支出、结余与最近记录。
- 记一笔：金额、商户、日期、分类、成员、账户与备注。
- 明细：搜索、收入/支出/待核对筛选；点记录可编辑。
- 统计：当月分类环形图，设置独立月预算。
- 邮件：同步加密文件或粘贴一封消费通知。
- 设置：导出加密备份、恢复、更改密码、CSV。

本机用户名不是云端账户，不能在另一台手机用相同用户名自动找回账本。密码丢失无法找回。Face ID 失效时使用账本密码；恢复备份时要使用该备份导出时的密码。

## 7. 真机验收清单

安装后先使用示例数据测试，不要立即依赖它保存唯一账目：

- 注册→锁定→正确密码解锁；错误密码不能解锁。
- 启用 Face ID→退后台→返回解锁；取消 Face ID 时仍可用密码。
- 新增、编辑、删除收支；月统计和预算一致。
- 导出加密备份，在保留当前备份后恢复，确认记录一致。
- 导入示例邮件两次，只计一次；删除后刷新不再出现。
- 选定同步文件、关 App 再解锁，文件仍可读取；云盘延迟时显示失败而不清空记录。
- 刷新免费签名后，账本和登录仍正常。

任何一项失败，请记录错误文字与 iOS 版本，暂不要录入唯一的真实账目。不要分享密码、配对密钥或真实邮件截图。
